# Extensions for Polylang

A useful set of extensions for the free version of [Polylang](https://wordpress.org/plugins/polylang/):

- **REST API**: `lang` and `translations` fields on the core endpoints of posts and terms, a `lang` filter on
  collections, a post created together with its translations in a single request, and the translation status of the
  site.
- **Inactive languages**: hide a language from visitors while you are still translating it.
- **Per-language blocks**: show a block only in some languages, so that a single header, footer or navigation works
  for every language in block themes.

When Polylang Pro is active, the features it already provides are turned off.

> **Status:** in development, not released yet.

## Requirements

WordPress 6.8 or later, PHP 7.4 or later, Polylang 3.9.2 or later.
